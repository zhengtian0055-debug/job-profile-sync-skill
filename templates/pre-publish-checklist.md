# 发布前核对清单

> 用途：在每个平台**发布/保存公开资料之前**逐项核对。
> 用法：每项打勾；任何一项未通过，先修复再发布。
> 建议：先跑"隐私检查"，再跑"真实性检查"，最后跑"一致性检查"（跨平台时）。

## A. 隐私检查（必须全过）

- [ ] 没有身份证号（含后几位）
- [ ] 没有完整证书/执照编号（只允许名称）
- [ ] 没有家庭住址、门牌号
- [ ] 没有银行卡号、支付信息
- [ ] 没有他人隐私信息（家人、同学、客户个人信息）
- [ ] 联系方式公开范围已确认（手机号/邮箱/微信分别确认过展示给谁）
- [ ] 照片（如头像）不包含敏感背景（证件、票据、屏幕信息）
- [ ] 平台要求的实名认证信息仅按最小要求提供，且确认不对外展示

## B. 真实性检查（必须全过）

- [ ] 每条信息都能回到"结构化资料表"/简历
- [ ] 公司/组织名称、岗位头衔与事实一致
- [ ] 起止时间准确（月-年 格式，全平台一致）
- [ ] 数据（人数、规模、百分比、奖项）真实可溯源，没有夸大
- [ ] 技能标签只选自己真实掌握/使用过的
- [ ] 证书只写自己真实取得/通过的，未出结果的标注"待确认"或"考试通过"
- [ ] 作品链接真实可访问，且确实由本人参与
- [ ] 未确认的信息已标注"待确认"，没有被当成事实填写

## C. 多平台一致性检查（跨平台核对）

- [ ] 教育背景（学校/专业/学历/时间）所有平台一致
- [ ] 每段经历的**时间、公司、头衔**所有平台一致
- [ ] 经历描述的核心事实一致（仅措辞侧重可不同）
- [ ] 证书/执照名称一致
- [ ] 联系方式一致（更新后逐平台同步）
- [ ] 头像/照片一致（如使用照片）
- [ ] 求职方向表述一致（不互相矛盾）

## D. 平台特定检查

- [ ] LinkedIn：头衔、About、公开范围已确认
- [ ] BOSS直聘：求职意向、期望城市、个人优势已确认
- [ ] 平台字段与当前页面实际字段一致（无遗漏、无错位）
- [ ] 预览已检查：无乱码、无错别字、无断行异常
- [ ] 保存/发布前已截图或预览留档（便于后续对比更新）
