# job-profile-sync-skill

**求职资料整理与多平台同步工作流**：把一份确认过的简历，整理并同步到 LinkedIn、BOSS直聘等招聘平台，同时生成 GitHub 个人主页 README 与作品集入口。

> 这是一个可复用的 AI Skill，不是求职中介，也不自动投递简历。登录、审核、提交始终由你本人完成。

---

## 解决什么问题

投多个平台时，简历往往要逐平台重填一遍，填着填着口径就不一致了；LinkedIn 字段多、BOSS直聘风格又不一样；GitHub 主页也不知道该放什么。

这个 Skill 把过程标准化为一条可重复的工作流：**资料确认 → 信息拆分 → 平台字段映射 → 平台文案生成 → 用户逐项录入 → 发布前核对 → 后续同步更新**。你只需要一份确认过的简历，AI 负责整理、映射、生成草稿和核对清单，你负责审核和提交。

## 适合谁

- 校招 / 社招 / 转行的求职者；
- 需要同时维护多个招聘平台资料的人；
- 想让 GitHub 主页更像一份作品集的人；
- **没有技术背景也能照着操作**——所有步骤都是清单式的。

## 快速开始

1. 准备一份**最终确认过的简历**（Word / PDF / 文本 / 在线文档均可）；
2. 对 AI 说：`用 job-profile-sync 把我的简历整理成多平台求职资料`；
3. 按输出的**结构化资料表**核对信息，标注待确认项；
4. 逐个平台打开，按**平台录入草稿**逐项填写（登录由你本人完成）；
5. 发布前跑一遍**核对清单**（隐私 / 真实 / 一致性），通过后再发布。

## 会生成什么

| 产物 | 说明 |
|---|---|
| 结构化资料表 | 所有平台共用的唯一事实源，避免口径漂移 |
| 平台录入草稿 | LinkedIn / BOSS直聘等，按平台特性调整表达 |
| 发布前核对清单 | 隐私检查、真实性检查、多平台一致性检查 |
| GitHub Profile README 草稿 | 一句定位 + 技能标签 + 精选作品 + 联系入口 |
| 更新维护指引 | 简历改版后如何同步更新所有平台 |

## 平台适配

- **LinkedIn**：头衔、个人简介（About）、教育、工作经历、技能、资格认证、项目、作品；
- **BOSS直聘**：求职意向、个人优势、工作经历、教育经历、技能标签、期望城市；
- **智联招聘 / 前程无忧 / 脉脉等**：通用字段映射。

> ⚠️ 平台字段名称、公开范围和功能会随时间变化。本 Skill 以**你当前页面的实际字段**为准，不假设界面永远不变。

## 隐私与真实性

- **最小公开**：只填岗位需要的字段；身份证号、完整证书编号、家庭住址、银行卡等不上平台；
- **不虚构**：每条信息都能回到简历；未确认的标"待确认"；
- **不存储**：本 Skill 不把简历变成资料存储工具，只在当前任务中使用你提供的资料；
- 平台要求的实名认证信息，仅按平台最小要求提供，通常只用于认证、不对外展示，如有疑虑先暂停核实。

## 工作流示意

```
简历(已确认)
    │ ① 资料确认（标注待确认）
    ▼
结构化资料表（唯一事实源）
    │ ② 信息拆分（公开 / 必填 / 可选 / 不公开）
    ▼
平台字段映射 ──► LinkedIn ──► BOSS直聘 ──► 其他平台
    │ ③ 以当前页面实际字段为准
    ▼
平台文案生成（同一事实，平台化表达）
    │ ④ 不虚构、不夸大
    ▼
用户本人逐项录入 → ⑤ 每板块核对
    ▼
发布前核对：隐私 ✓ 真实 ✓ 一致 ✓
    │ ⑥ 通过后才发布
    ▼
后续同步更新 ← 简历改版/新增经历时回到②
   ⑦
```
